2. Backup Content and Cloud Storage

Cloud Backup: Photo Storage allows users to back up supported content to cloud storage.

Depending on the features selected, permissions granted, device capabilities, and current App configuration, supported backup content may include:

  • Photos
  • Videos
  • Contacts
  • Documents
  • Files
  • Audio files
  • Music
  • Voice recordings
  • Supported files stored on external or removable storage, including an SD card where supported

Users choose which supported content or categories they want to back up.

Encryption of Backup Content

Supported backup files are encrypted on the user's device before they are uploaded to cloud storage.

Encrypted backup files are transmitted using encrypted network connections designed to protect the data while it is in transit.

After backup data reaches the cloud infrastructure, it remains encrypted while stored at rest using Amazon Web Services (AWS) infrastructure.

Supported backup content is therefore protected through the following stages:

  • Encryption on the user's device before upload
  • Encrypted transmission between the user's device and cloud infrastructure
  • Encryption while stored at rest in cloud infrastructure

Backup and Restore

When a user chooses to restore supported content, the App retrieves the applicable backup data and provides it to the authenticated user's device through the restore process.

An internet connection is required when content is uploaded to or retrieved from cloud storage.

3. Automatic Backup

The App may provide automatic backup for supported photos, videos, or other eligible content.

When a user enables automatic backup, the App may periodically identify newly available eligible content and upload it to cloud storage according to the user's backup settings, permissions, network availability, and applicable device restrictions.

Automatic backup may operate when the user is not actively interacting with the App where Android permits background processing.

Users can control automatic backup through the available App settings and Android permission controls.

Disabling automatic backup prevents future automatic uploads but does not automatically delete content that has already been backed up. Users may separately delete backed-up content where that functionality is available.

4. Private Vault

The App provides or may provide a Private Vault feature for restricting access to selected photos, videos, documents, or other supported content.

Depending on the current App version and device capabilities, the Private Vault may use:

  • A user-created PIN
  • Device authentication
  • Biometric authentication where supported
  • Other App-level access restrictions

The Private Vault is intended to help prevent unauthorized or casual access to selected content through the App.

The storage location and backup status of Vault content depend on the feature configuration and actions selected by the user.

If Vault content is included in cloud backup, the cloud-backup protections described in this Privacy Policy apply to that backed-up content.

Users are responsible for protecting:

  • Their Vault PIN
  • Device authentication credentials
  • Device access
  • Other security credentials

Users should not provide their Vault PIN through:

  • Advertising
  • Analytics
  • The optional assistant
  • Unsolicited messages
  • Ordinary customer-support requests
