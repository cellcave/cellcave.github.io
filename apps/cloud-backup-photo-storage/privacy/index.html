2. Backup Content and Cloud Storage

Cloud Backup: Photo Storage allows users to back up supported content to cloud storage.

Depending on the features selected, permissions granted, device capabilities, and current App configuration, supported backup content may include:

  • Photos
  • Videos
  • Contacts
  • Documents
  • Files
  • Audio files
  • Music
  • Voice recordings
  • Supported files stored on external or removable storage, including an SD card where supported

Users choose which supported content or categories they want to back up.

Encryption of Backup Content

Supported backup files are encrypted on the user's device before upload.

Encrypted backup files are transmitted using encrypted network connections and remain encrypted while stored using Amazon Web Services (AWS) infrastructure.

Supported backup content is therefore protected through:

  • Encryption on the user's device before upload
  • Encrypted transmission between the user's device and cloud infrastructure
  • Encryption while stored in cloud infrastructure

Cell Cave does not use the contents of users' backed-up files for advertising.

Backup and Restore

When a user chooses to restore supported content, the App retrieves the applicable backup data and provides it to the authenticated user's device through the restore process.

An internet connection is required when content is uploaded to or retrieved from cloud storage.

4. App Features and User-Controlled Processing

Automatic Backup

When a user enables automatic backup, the App may periodically identify newly available eligible content and upload it according to the user's selected backup settings, permissions, network availability, and applicable Android background-processing restrictions.

Users can disable automatic backup through the available App settings. Disabling automatic backup prevents future automatic uploads but does not automatically delete content that has already been backed up.

Private Vault

The App may provide a Private Vault or app-lock feature for restricting access to selected content.

Depending on the App version and device capabilities, the Private Vault may use:

  • A user-created PIN
  • Device authentication
  • Biometric authentication where supported

Users are responsible for protecting their Vault PIN, device credentials, and other security information.

Shared Folders and User-Initiated Sharing

The App may allow users to intentionally share supported files or folders with other people.

Depending on the available functionality, users may be able to:

  • Create shared folders
  • Select content to share
  • Invite another person using an email address
  • Grant supported view or edit permissions
  • Change or revoke sharing permissions where supported

When a user uses a sharing feature, information necessary to provide and manage that feature may be processed, including recipient email address, invitation information, account information, sharing permissions, and information necessary to operate the shared folder.

In-App Assistant

The App may provide an optional assistant that allows users to submit text questions and receive generated responses.

When a user chooses to use the assistant, submitted text is transmitted to and processed by infrastructure supporting the assistant. Assistant-related functionality may use AWS infrastructure and other processing services configured for this feature.

The assistant is optional and is not required for ordinary backup and restore functionality.

Users should not submit passwords, OTP codes, payment-card information, encryption keys, Private Vault PINs, or other highly sensitive security information to the assistant.

Machine-Learning Features

The App may use Google ML Kit to provide machine-learning-based features within the App.

The specific Google ML Kit functionality available may depend on the App version, device capabilities, and enabled App features.

No additional claims regarding the collection, storage, transmission, or sharing of information through Google ML Kit are made beyond the information-handling practices otherwise described in this Privacy Policy and the App's actual implementation.
