2. Backup Content and Cloud Storage

Cloud Backup: Photo Storage allows users to back up supported content to cloud storage.

Depending on the features selected and permissions granted, supported backup content may include:

  • Photos
  • Videos
  • Contacts
  • Documents
  • Files
  • Audio files
  • Music
  • Voice recordings
  • Supported content stored on external or removable storage, including an SD card where supported

Users decide which supported content they want to back up.

Encryption of Backup Content

Supported backup files are encrypted on the user's device before they are transferred to cloud storage.

Encrypted backup files are transmitted using encrypted network connections designed to protect the data while it is in transit.

After encrypted backup data reaches the cloud infrastructure, it remains encrypted while stored at rest using Amazon Web Services (AWS) infrastructure.

Supported backup content is therefore protected through multiple stages of the backup process:

  • Encryption on the user's device before upload
  • Encrypted transmission between the user's device and cloud infrastructure
  • Encryption while stored at rest in cloud infrastructure

Access to Backup Content

Backup files are encrypted before leaving the user's device.

Cell Cave does not access the contents of encrypted user backup files through the ordinary cloud-backup and storage process.

When a user chooses to restore backed-up content, the App retrieves the applicable backup data and makes it available to the authenticated user's device through the restore process.

Backup and restore operations require an internet connection when information is uploaded to or retrieved from cloud storage.

3. Private Vault

The App may provide a Private Vault feature that allows users to restrict access to selected photos, videos, documents, or other supported content inside the App.

The Private Vault may use a PIN and, where supported by the device and App configuration, device-based authentication features to restrict access.

Content placed in the Private Vault is handled according to the storage and security protections applicable to that content, including the backup and encryption protections described in this Privacy Policy where applicable.

The purpose of the Private Vault is to restrict ordinary access to selected content and help prevent that content from being readily visible to another person using the user's device.

Users are responsible for protecting:

  • Their Private Vault PIN
  • Device authentication credentials
  • Device access
  • Other security information associated with the Vault

Cell Cave does not ask users to provide their Private Vault PIN through advertising, analytics, the optional in-app assistant, or ordinary customer-support requests.
