# CELL CAVE Website

This is the production-ready static website for **CELL CAVE (SMC-PRIVATE) LIMITED**. It is designed for GitHub Pages and uses plain HTML, CSS, and JavaScript with centralized configuration.

## Update once → reflect everywhere

Edit **`assets/js/config.js`** to change global information:

- Brand name
- Legal company name
- Website URL (also used for canonical metadata)
- Official logo path
- Favicon path
- Support email
- Phone number (currently blank)
- Company address (currently blank)
- Google Play developer link
- Apple App Store landing page
- Social links (currently blank)
- Featured App ID

## App data

Edit **`assets/js/apps-data.js`** to update app information, store URLs, status, descriptions, icons, privacy routes, and features.

The homepage, Apps page, Support page, Featured App, and app detail pages read from this same centralized app catalog.

## Change the Featured App

In `assets/js/config.js`, change only:

```js
featuredAppId: "cloud-backup-photo-storage"
```

Use any valid app `id` from `assets/js/apps-data.js`.

## Global header and footer

The header and footer are generated by **`assets/js/site.js`** and injected into every page using `#siteHeader` and `#siteFooter`.

## Adding a new app

1. Add its icon to `assets/icons/` if available.
2. Add one app object to `assets/js/apps-data.js`.
3. Create a route folder at `apps/<slug>/` using the same small `index.html` shell as the existing app pages and set `data-app-id` to the new app ID.
4. Add an app-specific privacy page if required.

No homepage, Apps page, Support page, or Featured App markup needs to be rebuilt.

## GitHub Pages

Upload the complete project to the root of the `cellcave.github.io` repository and deploy from the `main` branch root.
