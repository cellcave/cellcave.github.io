1. Overview

All Video Downloader & Saver is provided by CELL CAVE ( SMC-PRIVATE ) LIMITED.

The app does not require users to create a CELL CAVE ( SMC-PRIVATE ) LIMITED account or provide a name, email address, phone number, or password to use its main functionality.

3. Photos, Videos, Music, Audio and Media Access

All Video Downloader & Saver may request access to photos, videos, music, audio, media, or related device storage when this access is needed to provide supported downloading, saving, media management, and Gallery Vault functionality.

Where supported by Android, the app may allow users to choose between Full Access and Limited Access to selected photos, videos, or other supported media.

The app uses only the media access granted by the user through applicable Android permission controls.

Media accessed for the app's normal functionality is handled locally on the user's device.

The app may allow users to paste a supported video link in order to download or save video content. The video link entered by the user is processed locally on the user's device as part of the app's normal functionality.

CELL CAVE ( SMC-PRIVATE ) LIMITED does not send or upload the video link entered by the user to a CELL CAVE ( SMC-PRIVATE ) LIMITED server as part of the normal link-based download process.

CELL CAVE ( SMC-PRIVATE ) LIMITED does not upload your photos, videos, music, audio, or downloaded media to a CELL CAVE ( SMC-PRIVATE ) LIMITED server as part of the app's normal functionality.

You may manage or revoke applicable permissions from your Android device settings. Some features may not function correctly if required access is disabled.

4. Gallery Vault

All Video Downloader & Saver includes a Gallery Vault feature that allows users to manage supported private media on their device.

Photos and videos used with the Gallery Vault remain locally on the user's device and are not uploaded to CELL CAVE ( SMC-PRIVATE ) LIMITED servers as part of the normal Gallery Vault functionality.

Users may create a PIN or password to protect access to the Gallery Vault.

The Gallery Vault PIN or password is stored or verified locally on the user's device and is not sent to CELL CAVE ( SMC-PRIVATE ) LIMITED servers as part of the normal Vault functionality.

Keep Your Vault Credentials Safe

Because the Vault PIN or password is handled locally, users should keep their device and Vault credentials secure.
